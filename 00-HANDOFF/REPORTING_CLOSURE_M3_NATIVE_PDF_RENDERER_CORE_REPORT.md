## Renderer behavior summary

`NativePdfReportRenderer` implements `IProductionReportRenderer`.

Status behavior:

- Renderer name: `Salryn.NativePdf.PDFsharpMigraDoc`
- Available: `true`
- Can render PDF: `true`
- Can preview: `false`
- Can print: `false`
- Requires external runtime: `false`
- Status code: `NativePdf.Available`

Render behavior:

- Accepts `ProductionReportRenderRequest`.
- Validates requested output through `ProductionReportOutputKinds.TryNormalize`.
- Allows only `pdf`.
- Rejects unsupported output kinds with `NativePdf.UnsupportedOutputKind`.
- Rejects invalid datasets with `NativePdf.InvalidDataset`.
- Respects cancellation token and request cancellation token.
- Builds PDF bytes in memory through MigraDoc/PDFsharp.
- Produces `ProductionReportArtifactMetadata` from the generated bytes.
- Computes SHA-256 from the in-memory PDF bytes.
- Sets content type to `application/pdf`.
- Sets file name from safe report kind plus generated timestamp.
- Sets renderer identity.
- Sets source dataset hash from `request.Dataset.DatasetSha256`.
- Does not write the PDF to disk.

- No embedded credentials.
- No direct SQL.

## Artifact factory behavior

`NativePdfArtifactFactory` creates metadata only.

It does not persist bytes. It does not choose a storage root. It does not create an export record.

Metadata fields populated:

- file name
- content type
- byte length
- output SHA-256
- created-at
- renderer name
- renderer version
- source dataset SHA-256
