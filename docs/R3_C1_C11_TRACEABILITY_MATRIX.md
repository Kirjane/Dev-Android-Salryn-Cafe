# Salryn Cafe R3 — Donor-to-Dev-to-R3 C1–C11 Traceability Matrix

This document records the authoritative functional, endpoint, RBAC permission, durable-intent, and executable verification traceability across the unified production R3 application (`/cafe/r3` & `/cafe/r3/*`), the Dev Host kernel (`Salryn.Api.Local`, `Salryn.Infrastructure`, `Salryn.Sync.Central.Server`), and the donor business requirements (`C1`–`C11`).

## Architecture & Surface Boundaries

- **Unified Production R3 Application:** Mounted in the production `apps/cafe-web/dist/` bundle at `/cafe/r3` and `/cafe/r3/*`, served directly by `Salryn.Api.Local` (`app.Map("/cafe", ...)`), with **zero** `import.meta.env.DEV` blocking, **zero** standalone mock backend, and **zero** preview persona switcher.
- **Preserved Legacy Surfaces:** `/cafe/`, `/cafe/orders`, `/cafe/kitchen`, `/cafe/backoffice`, and isolated `/cafe/central` remain intact and verified by `apps/cafe-web/e2e/run-cafe-e2e.mjs` (zero-mock bundle guard + 11/11 E2E assertions).
- **Host Startup Gate (Fail-Closed):** `GET /api/license/status` (`isLicenseActiveForBootstrap`) → `GET /api/bootstrap/status` (`POST /api/bootstrap/first-admin`) → `GET /api/session` (`POST /api/auth/login`) → `GET /api/system/identity` (binds `hostIdentityKey` + `actorUserId` for all v2 durable pending intents).
- **Durable Pending-Intent Authority (`apps/cafe-web/src/r3/live/durableIntent.ts`):** Persists v2 records (`salryn.cafe.r3.pending.<scope>.v2`) bound to `{ hostIdentityKey, actorUserId }` before HTTP dispatch, fails closed on corrupt `localStorage`, blocks cross-actor/cross-Host replay or discard, refuses to relabel post-commit `401`/`403` retry failures as discardable, and synchronizes across tabs via the `storage` event.

## External Release Gates (Explicitly Separate From Software Readiness)

1. **Release-Build Signed Machine-Bound Host License (`HUMAN_REQUIRED` / External Artifact):** Automated acceptance runs in Debug configuration use `DEBUG_DEVELOPMENT_LICENSE` (clearly labeled in evidence). Final Release deployment requires installing an Ed25519-signed `Salryn.Cafe` Host license generated for the target Windows machine.
2. **Physical ESC/POS Thermal Hardware (`HUMAN_REQUIRED`):** Receipt and kitchen print job creation, spooling, attempt state transitions, and idempotent retry are verified in software; physical paper feed/cutter verification requires the connected 58mm/80mm printer.
